# AIP-C01 Study Roadmap

The order follows the Skill Builder exam-prep plan and gives more time to heavier domains. Each task folder has the same files:

- `Study-Notes.md`: the master source
- `Architecture-Diagrams.md`
- `Practice-Questions.md`
- `Code-Examples.ipynb`: runs in mock mode by default
- `Study-Guide.pdf`

## Per-task routine (about 2–3 h)

1. Read `Study-Notes.md` §1–§9 (concepts and services).
2. Work through the notebook in mock mode, then optionally in live mode with a budget alert set.
3. Redraw one diagram from memory.
4. Answer `Practice-Questions.md` before opening any answers, and log misses in the weak-area checklist.
5. Revise from the PDF summary 2–3 days later (spaced repetition).
