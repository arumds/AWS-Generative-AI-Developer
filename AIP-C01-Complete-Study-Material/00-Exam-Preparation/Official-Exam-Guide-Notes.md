# AIP-C01 — Official Exam Guide Notes

✅ Verified 30 Oct 2026 from the [official exam guide](https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01.html). Always re-check the guide before booking; AWS updates it.

## Format

- **65 scored + 10 unscored** questions. The unscored ones are not identified.
- Question types:
  - **Multiple choice:** 1 correct answer, 3 distractors.
  - **Multiple response:** 2 or more correct answers out of 5+ options; you must select all correct answers to get credit.
- **Scaled score 100–1,000; passing score 750.** Scoring is compensatory: you pass on the overall score, not per domain.
- Unanswered questions count as wrong, and there is no penalty for guessing, so answer every question.
- I have not verified the exam duration. Check it on the exam's registration page.

## Domain 1, Task 1.1 skills (official wording, abridged)

- **1.1.1:** Create comprehensive architectural designs aligned to business needs and technical constraints (FMs, integration patterns, deployment strategies).
- **1.1.2:** Develop technical PoC implementations to validate feasibility, performance and business value before full-scale deployment (Amazon Bedrock).
- **1.1.3:** Create standardized technical components for consistent implementation across deployment scenarios (AWS Well-Architected Framework, WA Tool Generative AI Lens).
